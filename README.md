# Bitácora de Mantenimiento MM103 — app sin internet

App web instalable (PWA) para la tableta del equipo de mantenimiento del Condominio Maestro Meridiano 103.

- Los datos **no** viven en este repositorio: se descargan del servidor (Google Apps Script + Google Sheets) con el usuario y contraseña de cada persona, y se guardan solo en la tableta.
- Fase 1: consulta sin internet de la cola del día, checklist de equipos, tickets y almacén.
